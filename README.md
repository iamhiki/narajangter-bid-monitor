# 나라장터 입찰 공고 모니터링

전시 설계·시공 업체 (주)지일을 위한 나라장터 입찰 공고 자동 모니터링 서비스입니다.
매일 나라장터에 올라온 공고 중 **우리 회사가 참가할 만한 공고**를 골라 텔레그램으로 알리고,
입찰 담당자들이 함께 보며 참가 여부를 정하는 화면을 제공합니다.

## 무엇을 해 주나요

| 기능 | 설명 |
|---|---|
| 공고 자동 수집 | 나라장터 본공고·사전규격을 물품·용역·공사 전부 조회합니다 (공공데이터포털 API) |
| 우리 일인지 판정 | 제목 키워드, 보유 세부품명, 예산 금액으로 1차로 고르고, 무관한 공고는 제외 키워드로 거릅니다. 해외 개최 전시(한국관 등)와 마감이 지난 공고는 뺍니다 |
| 참가 자격 확인 | 나라장터 업종제한과 공고문 첨부의 참가자격·지역제한을 읽어 우리가 가진 자격과 비교합니다. 공동수급 허용 여부도 함께 보여 줍니다 |
| 싱크로율 | 지일이 과거에 수행한 사업의 과업지시서와 얼마나 비슷한지 % 로 보여 줍니다 |
| 텔레그램 보고 | 평일 09:00 입찰 공고(전날 게시분, 월요일은 금~일), 매주 월요일 09:10 협상·규격가격동시·사전규격(지난 7일). 보고된 공고는 구글 시트에도 쌓입니다 |
| 담당자 화면 | 공고 목록을 함께 보며 참가·보류·불참을 정하고, 담당자 지정·대화를 남깁니다. 보고된 공고는 판단 기록에 '미판단'으로 쌓이고, 판단 없이 마감되면 '놓침'으로 남습니다 |
| 판단 기록 백업 | 판단 기록을 구글 드라이브 폴더에 자동으로 복사하고(날짜별 30일), 드라이브에서 바로 볼 수 있는 표(`판단기록.csv`)도 함께 둡니다 |

## 흐름

```
나라장터 API ──▶ 수집 ──▶ 키워드·품목·금액 판정 ──▶ 첨부 문서로 자격·지역 확인 ──▶ 싱크로율
                                                                                  │
                                         ┌────────────────────────────────────────┤
                                         ▼                                        ▼
                                 텔레그램 보고 (평일·매주)                  담당자 화면 (사내망)
                                   │         │                               ▲          │
                                   ▼         ▼                               │          ▼
                               구글 시트   보고 기록 (report-log 브랜치) ─────┘     판단 기록
                                                       '미판단'으로 쌓임               │
                                                                                       ▼
                                                                          구글 드라이브 자동 백업
```

- 텔레그램 보고는 GitHub Actions에서 돌아 사무실 PC가 꺼져 있어도 나갑니다.
- 담당자 화면은 사무실 PC에서 돕니다. 꺼져 있던 동안 보고된 공고는 PC를 켜면 몇 분 안에 판단 기록에 들어옵니다.

판정은 전부 규칙(키워드·코드·금액·자격·첨부 문서 문장 규칙)과 과거 사업 대조로 하며, LLM(생성형 AI)은 쓰지 않습니다.
자세한 판정 순서는 [파이프라인 플로우차트](narajangter-bid-monitor/docs/파이프라인_플로우차트.md)에 있습니다.

## 주의

이 서비스의 판정은 **1차 스크리닝**입니다. '강력추천'이어도 입찰 참가 전에는 반드시
나라장터 원문 공고와 첨부 규격서를 직접 확인하세요.

## 저장소 구성

| 위치 | 내용 |
|---|---|
| [`narajangter-bid-monitor/`](narajangter-bid-monitor/) | 서비스 본체 — 설치·설정·실행 방법은 [README](narajangter-bid-monitor/README.md) 참고 |
| [`narajangter-bid-monitor/config/`](narajangter-bid-monitor/config/) | 키워드·제외 키워드, 보유 자격·세부품명(`held-qualifications.json`), 해외 개최 판정 목록 (코드 수정 없이 JSON만 고치면 반영) |
| [`.github/workflows/`](.github/workflows/) | 평일·매주 텔레그램 보고 자동 실행 (GitHub Actions). 보고된 공고 목록을 `report-log` 브랜치에 올립니다 |
| `report-log` 브랜치 | 보고에 나간 공고 목록 (공개된 공고 정보만). 담당자 화면이 받아 판단 기록에 쌓습니다 — 판단·담당자 이름은 올리지 않습니다 |
| [`gangwon-report/`](gangwon-report/) | 강원도 전시·체험 공고를 엑셀로 뽑는 1회성 스크립트 (본 서비스와 별개) |
