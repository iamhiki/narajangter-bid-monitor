# 담당자 알림, 카카오톡으로 보낼 수 있는가

> 사내 제안 · 나라장터 모니터링 알림 채널
> 작성일: 2026-09-16 · 모든 사실관계는 하단 출처 링크로 확인 가능

결론부터: **개인 카톡 자동화는 다시 시도해도 안 되지만, 카카오 공식 비즈니스 채널인 "알림톡"으로는 실제로 가능합니다.** 아래는 그 근거와 도입에 필요한 절차입니다.

## TL;DR

- 이전에 시도했던 "개인 카톡 자동 발송"이 막힌 건 실력 문제가 아니라, **카카오가 의도적으로 막아둔 구조**입니다 — 공식 API도 임의의 제3자에게는 발송 자체가 안 되고, 우회 시도는 이용약관 위반으로 계정 영구정지 대상입니다.
- 대신 **카카오톡 알림톡**이라는 공식 비즈니스 메시징 상품이 있고, 배송 알림·예약 확인 문자처럼 이미 국내 대부분 기업이 이 방식으로 카카오톡 알림을 보냅니다.
- 우리가 보내려는 메시지("신규 공고 알림")는 알림톡이 요구하는 **"정보성 메시지"** 조건에 정확히 맞고, 담당자가 채널을 따로 추가할 필요도 없습니다(전화번호만 있으면 발송 가능).
- 다만 카카오가 API를 직접 안 주고 **발송대행사(CSP)**를 거쳐야 하며, 사업자 심사·템플릿 사전승인·건당 비용이 발생합니다 — "이메일처럼 공짜에 즉시"는 아닙니다.

## 왜 예전 방식은 안 됐나

**✕ 공식 API도 임의의 상대에게 메시지를 못 보낸다**
카카오 개발자 문서에 따르면 카카오톡 메시지 API는 "나에게 보내기"(자기 자신에게만, 무제한)와 "친구에게 보내기"(그 서비스에 로그인하고 친구 목록 공개에 동의한 사람에게만)만 지원합니다. 서비스가 임의의 사용자에게 먼저 메시지를 보내는 기능 자체가 없습니다.

**✕ 비공식 자동화(매크로/역공학)는 계정 영구정지 대상**
카카오톡 운영정책상 이용약관을 벗어난 자동화는 위반 행위이며, 적발 시 한시적 또는 영구적으로 계정 이용이 제한됩니다. "더 잘 만들면 뚫린다"는 종류의 기술 난이도 문제가 아니라, 뚫리면 카카오가 막는 게 원래 설계입니다.

## 대안: 카카오톡 알림톡

알림톡은 카카오가 공식 제공하는 기업용 메시징 상품입니다. 택배 배송 안내, 병원 예약 확인, 주문 완료 알림처럼 평소에 받아본 "카카오톡 채널" 이름으로 오는 자동 메시지가 전부 이 방식입니다.

| | 알림톡 | 친구톡 |
|---|---|---|
| 메시지 성격 | ✅ 정보성 — 주문·배송·일정 등 필수 정보 | ⚠️ 광고성 — 프로모션·이벤트 가능 |
| 채널 친구 추가 | ✅ 불필요 — 전화번호만으로 발송 | ❌ 필수 — 채널 추가한 사람에게만 |
| 템플릿 사전심사 | ⚠️ 필요 — 정해진 양식만 허용 | ✅ 불필요 — 자유 구성 가능 |

> 우리가 보낼 메시지("OO 공고가 등록됐습니다, 예산 OO원, 마감 OO일")는 정보성 메시지이고 담당자가 채널을 추가할 필요도 없다는 점에서, 알림톡 조건에 정확히 들어맞습니다.

## 실제 이런 형태로 옵니다 (템플릿 예시)

```
[나라장터 입찰 모니터링]
신규 공고가 등록되었습니다.

공고명: #{공고명}
발주기관: #{발주기관}
예산: #{예산}
마감일: #{마감일}

자세히 보기: #{링크}
```

실제 승인 문구는 카카오 심사 기준(정보통신망법 + 카카오 내부 기준)에 맞춰 조정이 필요한 예시입니다.

## 도입 절차

1. **카카오톡 채널 개설 + 비즈니스 채널 인증** — 사업자등록증으로 카카오 심사를 받아 "비즈니스 채널"로 전환 (지일은 사업자등록증 이미 보유)
2. **발송대행사(CSP) 선정 및 계약** — 카카오가 API를 직접 주지 않아 알리고·비즈고·솔라피 등 대행사를 거쳐야 함 — 최소 2~3곳 견적 비교 권장
3. **메시지 템플릿 등록 및 사전심사** — 정보성 메시지 형식으로 작성해 제출 → 통상 영업일 2~3일 내 승인
4. **담당자 휴대폰 번호 확보** — 이메일 수신자 목록과 별개로 전화번호가 필요 (기존 `recipients.json`에 해당 필드 없음)
5. **개발: 리포트 발송 로직에 알림톡 호출 추가** — 기존 이메일 발송(`sendReportEmail.ts`)과 나란히, CSP가 제공하는 API를 호출하는 코드 추가 — 이 부분은 CSP 확정 후 바로 작업 가능

## 비용

| 구분 | 확인된 값 | 출처 |
|---|---|---|
| 알림톡 표준 단가 | 건당 약 **13원**(VAT 별도) | Solapi 공개 요금표 |
| 대량 발송 할인 | 발송량에 따라 최대 **57.69%** 할인 (대량이면 건당 5.5원대까지) | Solapi |
| 참고: SMS 단문 | 건당 18원 | Solapi |
| 참고: 카카오 브랜드메시지 | 건당 53~103원 | Solapi |

### 우리 규모로 계산하면

현재 수신자 3명, 매일 발송 기준으로 "하루 1건 요약 알림"을 3명에게 보낸다고 가정하면:

- 3명 × 30일 = **월 90건**
- 90건 × 13원 ≈ **월 1,170원** (할인 미적용, 순수 종량제 기준)

건당 단가만 보면 사실상 무시할 수 있는 금액입니다. **문제는 건당 단가가 아니라 대행사의 "월 최소 청구액" 구조**입니다.

> ⚠️ 소량 발송자에게 불리한 요금제가 실제로 존재합니다: 한 업체는 **"월 1만 건 미만이면 최소 5만원 청구"**, 다른 업체는 **"월 기본료 3만원(무료 3,300건 포함)"** 구조를 씁니다. 우리처럼 월 90건 정도만 보내도 이런 업체를 고르면 건당 계산과 무관하게 매달 3~5만원을 낼 수 있습니다. 반대로 **실사용량만큼만 청구하는 후불 종량제 공식 딜러사**(인포뱅크 계열 등)를 고르면 진짜 월 1,000~2,000원 수준으로 끝날 수도 있습니다.
>
> 그래서 견적 요청 시 "건당 얼마예요?"가 아니라 **"월 90~300건 정도 보내면 한 달 총액이 얼마이고, 월 최소 청구액이 있나요?"**라고 구체적으로 물어봐야 실제 비용을 알 수 있습니다.

## 세 가지 방식 정리

| 방식 | 가능 여부 | 비용 | 비고 |
|---|---|---|---|
| 이메일(현행) | ✅ 사용 중 | 무료 | 이미 매일 발송 중, 별도 조치 불필요 |
| 개인 카톡 자동화 | ❌ 불가 | - | 공식 API 미지원 + 이용약관 위반(계정 정지 위험) |
| 카카오톡 알림톡 | ⚠️ 가능·절차 필요 | 건당 ~13원 + 대행사별 월 최소 청구액 주의 | 채널 개설·CSP 계약·템플릿 심사 선행 필요 |

## 다음 단계 제안

1. CSP 2~3곳(알리고 / 비즈고 / 솔라피 등)에 우리 발송량 기준 실제 견적 요청
2. 견적·조건 비교 후 팀 승인
3. 카카오톡 채널 개설 + 템플릿 심사 신청 (병행 진행 가능)
4. 승인 완료 후 개발 착수 (기존 이메일 발송 코드와 병렬 구조로 추가)
